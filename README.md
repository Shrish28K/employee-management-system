# Employee Management System

A CLI-based Employee Management System built using Python and SQLite with support for authentication, employee record management, filtering, audit logging, and secure workspace handling.

## Features

- Workspace-based database management
- Secure authentication using bcrypt
- CRUD operations for employee records
- Dynamic employee filtering
- Conditional deletion using filters
- Audit logging system
- Input validation
- Safer SQL query handling

## Tech Stack

- Python
- SQLite3
- bcrypt
- tabulate
