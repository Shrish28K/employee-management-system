# Employee Management System

A CLI-based Employee Management System built using Python and SQLite with support for authentication, employee management, filtering, audit logging, and secure workspace handling.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![SQLite](https://img.shields.io/badge/Database-SQLite-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

# 🎯 Overview

This project is a modular Employee Management System designed to strengthen backend development fundamentals using Python and SQLite.

The system demonstrates practical implementation of:

- Authentication systems using bcrypt
- CRUD operations with SQLite
- Dynamic filtering and conditional deletion
- Audit logging
- Modular OOP architecture
- Input validation and SQL safety

---

# ✨ Features

## Employee Management
- Add employee records
- View employee details
- Update employee information
- Delete employee records
- View all employees

## Filtering System
- Dynamic filtering using conditions
- Numeric and string-based filtering
- Conditional deletion using filters

## Authentication & Security
- Workspace-based database management
- Secure password hashing using bcrypt
- Input validation
- Safer SQL query handling

## Logging System
- Audit logs for admin actions
- Timestamp-based activity tracking

# 🚀 Quick Start

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/employee-management-system.git

cd employee-management-system

pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```
